# Knowledge base index

Start here. Pick the task that matches what the user is asking for, then read the listed files in order.

---

## Task path 1 — I want to create an agent

1. `agent-design.md` — the 7-step Create framework (mission, scope, I/O, knowledge, reliability, tone, tests).
2. `agent-patterns.md` — pick one of ~23 reusable patterns that matches the agent's shape.
3. `kb-architecture-and-template.md` — how to structure the knowledge base (modular, frontmatter, chunking) + KB template.
4. `reliability-and-default-rules.md` — fact / inference / hypothesis / absence rules + portable 6-rule baseline to install in every produced agent.
5. `platform-quirks.md` — **only when** the user names a specific target (Custom GPT / Claude Project / Gem). Default agents are platform-agnostic.
6. `create-output-and-checklist.md` — the 8-section format for your final output + pre-publish checklist.

---

## Task path 2 — I want to refactor an existing agent

1. `refactor-checklist-and-template.md` — the 11-item checklist to run against the existing agent + 4-section format for the diagnostic report.
2. `kb-architecture-and-template.md` — assess whether the existing KB is modular or monolithic.
3. `reliability-and-default-rules.md` — assess whether reliability rules are present and how to improve them.
4. `platform-quirks.md` — **only if** the existing agent runs (or will run) on Custom GPT / Claude Project / Gem. Skip for platform-agnostic agents.

---

## Task path 3 — I want to structure a knowledge base

1. `kb-architecture-and-template.md` — principles + chunking guidance + KB template.
2. `platform-quirks.md` — per-platform file and size limits.

---

## Reference files (use as needed)

- `agent-patterns.md` — library of ~23 patterns, plus combinations.
- `reliability-and-default-rules.md` — portable baseline rules to install in any produced agent.
