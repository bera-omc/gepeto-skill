# Knowledge base index

Start here. Pick the task that matches what the user is asking for, then read the listed files in order.

---

## Task path 1 — Create an agent

1. `agent-design.md` — 7-step Create framework.
2. `agent-patterns.md` — pick one of ~23 reusable patterns.
3. `kb-architecture.md` — how to structure the knowledge base.
4. `reliability-and-default-rules.md` — reliability rules + 6-rule portable baseline.
5. `platform-quirks.md` — **only when** the user names a specific target (Custom GPT / Claude Project / Gem). Skip for platform-agnostic agents.
6. `create-output-template.md` — 8-section format for the final output.

---

## Task path 2 — Refactor / review / improve an existing agent

1. `refactor-checklist.md` — 11-item checklist to run against the agent.
2. `kb-architecture.md` — assess whether the KB is modular or monolithic.
3. `reliability-and-default-rules.md` — assess reliability rules and default posture.
4. `platform-quirks.md` — **only if** the agent targets a specific platform.
5. `refactor-output-template.md` — 4-section diagnostic format.

---

## Task path 3 — Structure a knowledge base

1. `kb-architecture.md` — principles + chunking guidance.
2. `platform-quirks.md` — per-platform file and size limits.
